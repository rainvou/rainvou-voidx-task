# Product Brief: TaskManager

## Executive Summary

소프트웨어 개발 팀은 Jira, Linear, Asana 등 기존 태스크 관리 도구를 사용하지만, 수동적인 상태 업데이트, 단절된 컨텍스트, 반복적인 리포트 작성에 여전히 많은 시간을 소비합니다. TaskManager는 AI 에이전트가 태스크의 생성부터 완료까지 전 과정을 능동적으로 보조하는 차세대 팀 협업 태스크 관리 시스템입니다.

Git 활동 분석으로 태스크 상태를 자동 전환하고, 자연어로 태스크를 생성하며, 리스크를 선제적으로 예측합니다. 개발자는 코드에 집중하고, PM은 보고서 대신 의사결정에 집중할 수 있습니다. 지금이 적기인 이유는 LLM 기술의 성숙으로 자연어 이해와 코드 분석이 실용적 수준에 도달했기 때문입니다.

## 문제

**개발 팀이 겪는 핵심 고통:**

- **수동 상태 관리의 비효율:** 개발자가 코드를 작성하고도 별도로 Jira 티켓 상태를 변경해야 합니다. 까먹으면 대시보드가 현실을 반영하지 못합니다.
- **단절된 컨텍스트:** 태스크, 코드, 문서, 채팅이 각각 다른 도구에 흩어져 있어 "이 태스크의 맥락이 뭐였지?"를 매번 추적해야 합니다.
- **비생산적 미팅과 리포트:** 스탠드업 미팅 준비, 주간 보고서 작성, 스프린트 리뷰 자료 만들기에 팀 리더급 인력의 시간이 소모됩니다.
- **리스크의 후행적 발견:** 프로젝트 지연은 데드라인이 지나서야 인지됩니다. 선제적 경고 시스템이 없습니다.

## 솔루션

TaskManager는 세 가지 핵심 축으로 이 문제를 해결합니다:

1. **AI 에이전트 자동화:** 자연어 태스크 생성, Git 활동 기반 상태 자동 전환, 리스크 예측, 회의록에서 액션 아이템 자동 추출. 사람이 하던 반복 작업을 AI가 대신합니다.
2. **통합 컨텍스트:** 태스크 안에서 Git 커밋, PR, 관련 문서, 채팅 이력이 하나로 연결됩니다. 모든 맥락이 한 곳에 있어 컨텍스트 스위칭이 사라집니다.
3. **실시간 팀 협업:** 칸반/간트/커스텀 대시보드, 비동기 스탠드업, 실시간 코멘트와 팀 프레즌스로 동기·비동기 협업 모두 지원합니다.

## 차별화 포인트

| 기존 도구 | TaskManager |
|----------|-------------|
| 수동 상태 업데이트 | Git/CI 활동 기반 자동 상태 전환 |
| 별도 리포트 작성 | AI 자동 요약 및 다이제스트 |
| 태스크-코드 수동 연결 | 태스크 키 기반 자동 양방향 연결 |
| 사후적 리스크 인지 | AI 리스크 예측 + 선제적 에스컬레이션 |
| 도구 간 컨텍스트 분산 | 통합 컨텍스트 (문서+채팅+코드 원스톱) |

핵심 차별점은 **AI가 관찰자가 아니라 능동적 참여자**라는 점입니다. 단순 대시보드가 아니라, 태스크를 분해하고, 담당자를 추천하고, 지연을 예측하는 프로액티브 에이전트입니다.

## 대상 사용자

**Primary — 소프트웨어 개발 팀 (5~50명):**
- PM: 로드맵 관리, 자동 리포트, 리소스 플래닝
- 개발자: CLI 기반 태스크 관리, Git 자동 연동, 포커스 모드
- QA: 구조화된 버그 리포트, 테스트 케이스 연동

**Secondary — 경영진 / 스테이크홀더:**
- 포트폴리오 뷰, 비용 추적, AI 기반 프로젝트 예측

## 성공 기준

- **팀 생산성:** 태스크 관리에 소요되는 시간 50% 감소 (수동 상태 변경, 리포트 작성 제거)
- **프로젝트 가시성:** 대시보드 정확도 95% 이상 (AI 자동 상태 추적 기반)
- **리스크 관리:** 프로젝트 지연 30% 감소 (AI 선제적 경고 기반)
- **사용자 채택:** 팀 내 일일 활성 사용률 80% 이상

## 스코프

**MVP (v1.0):**
- 계층형 태스크 관리 (Epic/Story/Subtask), 칸반 보드, 커스텀 상태
- Git 통합 (브랜치/커밋/PR ↔ 태스크 자동 연결)
- AI 자연어 태스크 생성, 자동 상태 전환
- 팀 대시보드 (번다운 차트, 벨로시티)
- 실시간 코멘트, @멘션
- REST API

**v1.0에서 제외 (후속 버전):**
- 게임화, 소셜 피드
- 멀티 조직 지원
- IDE 플러그인
- 간트 차트, 리소스 플래닝
- 디자인 파일 임베드

## 비전

2~3년 후 TaskManager는 단순한 태스크 관리 도구를 넘어 **AI 기반 소프트웨어 개발 운영 플랫폼**으로 진화합니다. AI 에이전트가 프로젝트 계획 수립부터 리소스 배분, 리스크 관리, 회고 분석까지 소프트웨어 개발 라이프사이클 전체를 지능적으로 오케스트레이션하는 플랫폼이 최종 비전입니다.
