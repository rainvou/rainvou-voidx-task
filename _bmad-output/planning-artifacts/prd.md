**Author:** voidx

## Executive Summary

TaskManager는 AI 에이전트가 태스크의 생성부터 완료까지 전 과정을 능동적으로 보조하는 팀 협업 태스크 관리 시스템입니다. 소프트웨어 개발 팀이 겪는 수동 상태 관리, 단절된 컨텍스트, 반복적 리포트 작성 문제를 해결합니다.

Git 활동 분석으로 태스크 상태를 자동 전환하고, 자연어로 태스크를 생성하며, 리스크를 선제적으로 예측합니다. 개발자는 코드에 집중하고, PM은 보고서 대신 의사결정에 집중할 수 있습니다.

### What Makes This Special

기존 태스크 관리 도구(Jira, Linear, Asana)와의 핵심 차별점은 **AI가 관찰자가 아니라 능동적 참여자**라는 점입니다. 단순 대시보드가 아니라 태스크를 분해하고, 담당자를 추천하고, 지연을 예측하는 프로액티브 에이전트입니다. Git/CI 파이프라인과의 긴밀한 통합으로 수동 상태 업데이트를 제거하여 대시보드가 항상 현실을 반영합니다.

## Product Scope

### MVP (v1.0)

핵심 가치를 증명하는 최소 기능 세트:

- 계층형 태스크 관리 (Epic/Story/Subtask)
- 칸반 보드 + 커스텀 워크플로우 상태
- Git 통합 (브랜치/커밋/PR ↔ 태스크 자동 연결)
- AI 자연어 태스크 생성
- AI 자동 상태 전환 (Git 활동 기반)
- 팀 대시보드 (번다운 차트, 벨로시티)
- 실시간 코멘트, @멘션
- 역할 기반 접근 제어
- REST API
- 태스크 키 (PROJ-123)

### Growth (v2.0)

채택 확대와 깊은 통합:

- AI 태스크 자동 분해, 스마트 할당, 리스크 예측
- Slack/Teams 양방향 연동
- CI/CD 빌드/배포 상태 반영
- 트리거-액션 자동화 엔진
- 간트 차트, 리소스 플래닝
- 비동기 스탠드업
- 릴리즈 관리, 릴리즈 노트 자동 생성
- GraphQL API

### Vision (v3.0+)

AI 기반 개발 운영 플랫폼:

- AI 회고 분석, 미팅 노트→태스크 자동 변환
- 게임화 (경험치/배지/리더보드)
- 멀티 조직 지원
- IDE 플러그인 (VS Code, JetBrains)
- 태스크+문서+위키 통합
- 포트폴리오 뷰, 비용 추적

## User Journeys

### Journey 1: 개발자 — 일일 개발 워크플로우

**페르소나:** 프론트엔드 개발자, 팀 5명, 스프린트 기반 작업

1. 아침에 TaskManager를 열면 **오늘의 태스크** 목록이 우선순위순으로 표시됨
2. 태스크 PROJ-42를 선택하면 관련 **PR, 코멘트 이력, 수용 기준**이 한 화면에 보임
3. "시작" 클릭 → 자동으로 `feature/PROJ-42` **Git 브랜치 생성**
4. 코드 작성 후 커밋 시 `PROJ-42` 키가 포함되면 → 태스크에 **커밋 자동 링크**
5. PR 생성 → 태스크 상태 자동 **"Review"로 전환**
6. PR 머지 → 태스크 상태 자동 **"Done"으로 전환**
7. 별도의 상태 업데이트 조작 **불필요**

**필요 기능:** 태스크 뷰, Git 통합, 자동 상태 전환, 태스크 키 시스템

### Journey 2: PM — 스프린트 관리

**페르소나:** PM, 10명 개발팀 관리, 2주 스프린트

1. 스프린트 시작 시 자연어로 "사용자 인증 시스템 구현" 입력
2. AI가 **Epic → Story → Subtask**로 자동 분해하여 제안
3. 칸반 보드에서 각 Story를 팀원에게 **드래그앤드롭 할당**
4. 스프린트 중간에 대시보드에서 **번다운 차트** 확인
5. AI가 "PROJ-15는 의존성 블로커로 2일 지연 예상" **리스크 경고**
6. 스프린트 종료 시 AI가 **벨로시티 리포트** 자동 생성
7. 스테이크홀더에게 **자동 생성된 진행 보고서** 공유

**필요 기능:** AI 태스크 분해, 칸반 보드, 대시보드, 리스크 예측, 자동 리포트

### Journey 3: QA — 버그 트래킹

**페르소나:** QA 엔지니어, 릴리즈 전 테스트 담당

1. 버그 발견 시 **구조화된 버그 리포트 템플릿**으로 태스크 생성
2. 스크린샷 첨부, 재현 단계 작성
3. AI가 **유사 버그 자동 감지** → "PROJ-31과 유사합니다" 안내
4. 버그 수정 PR이 머지되면 태스크 자동 **"QA 검증" 상태**로 전환
5. 검증 완료 → Done, 검증 실패 → 자동 **리오픈**
6. 이전에 수정된 버그 재발 시 **리그레션 자동 감지** 알림

**필요 기능:** 버그 템플릿, 중복 감지, 자동 상태 전환, 리그레션 추적

## Innovation & Novel Patterns

### 1. AI 기반 자동 상태 전환

**혁신 내용:** Git 웹훅 이벤트(push, PR 생성, PR 머지, CI 결과)를 실시간 분석하여 태스크 상태를 자동 전환합니다. 개발자가 수동으로 상태를 변경할 필요가 없습니다.

**기술 접근:** Git 웹훅 → 이벤트 파서 → 태스크 키 매칭 → 상태 규칙 엔진 → 자동 상태 전환

**리스크:** 오탐지 (잘못된 상태 전환) → 수동 오버라이드 + 규칙 커스터마이징으로 완화

### 2. 자연어 태스크 생성

**혁신 내용:** "로그인 페이지에 Google 소셜 로그인 추가"라는 자연어 입력을 LLM이 분석하여 제목, 설명, 수용 기준, 라벨, 예상 스토리 포인트가 포함된 구조화 태스크로 변환합니다.

**기술 접근:** 사용자 입력 → LLM API → 구조화 출력 (JSON) → 태스크 생성 API

**리스크:** LLM 환각 → 생성 전 미리보기 + 사용자 확인 단계 필수

### 3. 프로액티브 리스크 예측

**혁신 내용:** 태스크 의존성, 과거 벨로시티, 현재 워크로드를 분석하여 지연 확률을 예측하고 선제적 경고를 제공합니다.

**기술 접근:** 히스토리 데이터 + 현재 상태 → 통계 모델 + LLM 분석 → 리스크 스코어 + 대응 제안

**리스크:** 초기 데이터 부족 → 최소 2~3 스프린트 학습 기간 필요, 규칙 기반 폴백
