# Product Brief Distillate: TaskManager

## MVP 기능 상세

### Core 태스크 관리
- Epic > Story > Subtask > Checklist 4단계 계층 구조
- 커스텀 워크플로우 상태 (팀별 정의 가능)
- 긴급도×중요도 매트릭스 기반 우선순위 + AI 자동 조정
- 태스크 간 의존성 (blocks/blocked-by/relates-to) + 크리티컬 패스 계산
- PROJ-123 형태 태스크 키, Git 커밋/PR 자동 매핑
- 태스크 템플릿, 벌크 오퍼레이션

### AI 에이전트 (MVP)
- 자연어 → 구조화 태스크 생성
- Git diff 분석 기반 태스크 상태 자동 전환 (PR 머지→Done, 리뷰 요청→Review)
- 코드 활동 기반 진행률 자동 추정
- 유사/중복 태스크 자동 감지

### AI 에이전트 (후속)
- 큰 요구사항 → Epic/Story/Subtask 자동 분해
- 스킬셋·워크로드·성과 기반 담당자 추천
- 지연 확률·블로커 예측·번다운 이상 감지
- 코멘트/변경 이력 자동 요약, 팀 다이제스트
- 회의록 → 액션 아이템 추출
- 스프린트 회고 AI 분석
- 관련 문서/코드/과거 이슈 컨텍스트 서제스트

### 팀 협업
- 태스크별 스레드 코멘트, @멘션, 리액션
- 역할 기반 접근 제어 (Admin/PM/Dev/Viewer)
- 비동기 스탠드업 (어제/오늘/블로커 자동 수집)
- 팀 워크로드 밸런싱 시각화

### 대시보드/시각화 (MVP)
- 칸반 보드 (커스텀 컬럼, WIP 제한, 스윔레인)
- 번다운/번업 차트
- 벨로시티 트래킹
- 커스텀 대시보드 위젯 빌더

### 대시보드/시각화 (후속)
- 간트 차트 (의존성 포함)
- 히트맵 (생산성)
- 의존성 네트워크 그래프
- 리스크 매트릭스

### 워크플로우 자동화
- 트리거-액션 엔진 (상태 변경 → Slack 알림 등)
- 승인 프로세스, SLA 에스컬레이션
- 반복 태스크 (cron 기반)
- 커스텀 웹훅

### 통합/연동 (MVP)
- Git 통합 — 브랜치/커밋/PR ↔ 태스크 자동 연결
- REST API (API 퍼스트 설계)

### 통합/연동 (후속)
- Slack/Teams 양방향 연동
- CI/CD 빌드/배포 상태 반영
- 캘린더 동기화
- Notion/Confluence 문서 연동
- GraphQL API
- IDE 플러그인 (VS Code, JetBrains)

## 역할별 요구사항 힌트

### PM
- 프로젝트 로드맵 뷰 (마일스톤)
- 리소스 플래닝 (가용시간 vs 할당량)
- 스테이크홀더용 자동 보고서
- 릴리즈 관리 (버전별 태스크, 릴리즈 노트 자동)
- OKR 연동

### 개발자
- CLI 인터페이스 (터미널 태스크 관리)
- 태스크 시작 시 Git 브랜치 자동 생성
- PR 리뷰 코멘트 ↔ 태스크 코멘트 동기화
- 포커스 모드 (미니멀 뷰)

### 디자이너
- Figma/Sketch 프레임 임베드
- 디자인 리뷰 워크플로우
- 스크린샷 마크업/코멘트

### QA
- 구조화 버그 리포트 템플릿
- 테스트 케이스 매핑
- 리그레션 자동 리오픈

### 경영진
- 포트폴리오 뷰 (전체 프로젝트 조감도)
- 비용 추적 (시간×인건비)
- AI 완료일 예측, 리스크 시나리오

## SCAMPER 혁신 포인트
- 게임화 (경험치/배지/리더보드) — 후속 버전
- 태스크+문서+위키 통합 — 후속 버전
- 이슈 트래커+실시간 채팅 결합 — 후속 버전
- 시간 추적 내장 — 후속 버전
- 소셜미디어 피드식 팀 활동 타임라인 — 후속 버전
- 신규 팀원 온보딩 자동화 — 후속 버전

## 명시적 제외 (v1.0)
- 게임화, 소셜 피드
- 멀티 조직/외부 협력사 게스트
- IDE 플러그인
- 간트 차트, 리소스 플래닝 고급 기능
- 디자인 파일 임베드
- 개인 생산성 (투두/습관/목표)
- 라이브 커서 (동시 편집)

## 기술적 컨텍스트
- API 퍼스트 설계 필수
- 대시보드 연동 (기존 .voidx 설정 활용 가능)
- Git 통합이 핵심 차별점 — 첫 날부터 필요
- 실시간 기능 필요 (WebSocket 고려)
